# Privacy Policy

---

## 1. Introduction

This website, “Forkcast”, is a school project developed by Forkcast Solutions at HTL Leonding, Upper Austria. The
website is provided free of charge and can be used by anyone. As this is a work in progress, no guarantees regarding
availability, accuracy, or functionality are given.

---

## 2. Data We Collect

We collect and store user data strictly for functional purposes of the website. This includes

- Username
- Email address
- Login credentials
- Saved recipes and meal selections
- Favorite items or ingredients

No payment data is collected or processed at any time.

---

## 3. Purpose of Data Processing

The collected data is used solely to

- Provide account functionality
- Enable the meal planner and recipe features
- Store user preferences and selections
- Ensure basic operation and security of the website

---

## 4. Data Storage

All data is stored in a database. Appropriate technical measures are taken to protect the data within the scope of this
school project. However, as this is a non-commercial project, no guarantees regarding data security can be provided.

---

## 5. User Rights and Data Management

Users may modify or delete their data themselves if such functionality is available on the website. If this
functionality is not yet implemented, users may request changes or deletion of their data by contacting the team via
email. Requests will be processed as soon as possible.

---

## 6. Data Sharing
